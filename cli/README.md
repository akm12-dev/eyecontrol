# EyeControl CLI

Technician console of EyeControl. Installs the `eyecontrol` command.

```powershell
python -m pip install -e .\cli          # from the repository root
eyecontrol                              # interactive console
eyecontrol status                       # one-shot command
```

See the repository [README](../README.md) and [docs/architecture.md](../docs/architecture.md).
